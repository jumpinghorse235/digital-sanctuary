📿 Digital Sanctuary
A minimalist meditation and chanting sanctuary designed for discipline, focus, and spiritual transformation.

Digital Sanctuary is a privacy-first, fully local React web application that helps you maintain a daily chanting practice. With an elegant mobile-first design, it tracks your repetitions, visualizes your consistency, and provides a distraction-free environment for your spiritual growth.

✨ Features
🎵 Smart Audio Player: Play, pause, adjust tempo (0.75x to 1.25x), and utilize the seek bar for precise audio control.

🔁 Auto-Looping & Tracking: Automatically loops chants until you reach your customizable daily repetition target (e.g., 108 reps).

📖 Bilingual Lyrics: Immersive full-screen lyrics view featuring both original Hindi scripts and English translations.

🔥 Habit Tracking: Keeps track of your daily streaks and displays your consistency via a beautifully rendered 5-week Heatmap and Pulse Chart.

🌙 Theming & Audio: Toggle between Dark and Light modes, and control ambient volume directly within the app.

🔒 100% Offline & Private: No backend, no accounts, no tracking. All progress is securely saved to your browser's localStorage.

🛠️ Tech Stack
Framework: React 19 + Vite

Styling: Tailwind CSS v4

Animations: Framer Motion

Charts: Recharts

Icons: Lucide React

Data Management: LocalStorage API
